# Aegion

Industrial I/O Controller

## Overview

Aegion is an industrial-oriented I/O controller board designed for
machine automation and control applications.

The project focuses on robust field I/O, protected power interfaces,
and reliable industrial communication.

## Intended Applications

- Industrial machine control
- Automation equipment
- Distributed I/O systems
- Robotics infrastructure
- Embedded control systems

## Planned Features

- STM32 microcontroller
- 24 V industrial digital inputs
- Protected digital outputs
- Analog input interface
- CAN communication
- RS-485 communication
- Protected power input
- Status and diagnostic indicators

## Hardware

The PCB is designed using KiCad.
